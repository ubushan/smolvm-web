Проблема

ИИ-агент — это недоверенный исполнитель с правами разработчика

Утечка секретов

Агент видит токены, ключи API и переменные окружения и может отправить их наружу

Prompt injection

Чужая веб-страница, issue или README может дать агенту команду, о которой пользователь не знает

Необратимые действия

Удаление репозитория, merge, релиз, деплой — одним вызовом API

Нет следов

На рабочей машине действия агента не отличить от действий человека

smolvm-web · изоляция ИИ-агентов · 2

Агенты вроде Claude Code, Codex, OpenCode выполняют команды сами. Если запускать их на рабочем ноутбуке, у агента те же права, что у разработчика: доступ к ~/.ssh, токенам, корпоративной сети. При этом агент читает недоверенный контент из интернета — и может быть им перехвачен.
