Слой 3 · Секреты

Агент пользуется ключом, но никогда его не видит

Шлюз секретов на хосте

В машине — токен-заглушка; шлюз подставляет настоящий ключ при запросе к разрешённому API

Зашифрованное хранилище

Ключи привязываются к конкретным машинам; в журнал попадают без значений

Лимит запросов в день

Сверх лимита шлюз отвечает 429: зациклившийся агент не сожжёт бюджет

Зачем

Даже полностью перехваченный агент не может унести ключ: его нет в машине. Отзыв — смена токена, без перевыпуска ключа.

smolvm-web · изоляция ИИ-агентов · 7

Для локальных моделей (Ollama, vLLM, LM Studio) агенты настраиваются автоматически — данные вообще не покидают периметр. Для опасных вызовов API у секрета есть правила подтверждения, например DELETE или merge в GitHub — об этом через слайд.
