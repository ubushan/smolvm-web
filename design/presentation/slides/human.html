Необратимое — с подтверждения, опасное — одной кнопкой стоп

Подтверждение

  • Вызовы API по правилам секрета: DELETE, merge, релизы, деплои
  • Незнакомый адрес в сети: «на 10 минут», «всегда» или «запретить»
  • Нет ответа за 2 минуты — отказ; каждое решение в аудите

Kill switch «Изолировать»

  • Обрывает все соединения машины
  • Меняет токены шлюза — старые не работают
  • Ставит машину на паузу и блокирует запуск
  • «Остановить всех агентов» — для всех машин сразу

smolvm-web · изоляция ИИ-агентов · 9

Подтверждение: запрос агента реально задерживается на шлюзе, пока человек не нажмёт кнопку; для GitHub правила заполнены заранее. Kill switch для инцидента: машина ставится на паузу, а не удаляется — память и диск сохраняются для расследования. Изоляция переживает перезапуск smolvm-web. Дополнительно есть лимиты: число процессов агента, время работы агента (по истечении — автоостановка) и запросы API в день.
