# Макеты интерфейса и презентация

Черновые материалы, в работу интерфейса не входят.

## mockups/

Статичные макеты страниц (формат Design Component, `.dc.html`; раскладка холста — `canvas.json`).

Выбранное направление:

| Файл | Что это |
|---|---|
| `Workspaces.dc.html` | B · Рабочие места — главная страница |
| `Main.dc.html` | A · Одна кнопка — окно «Новая песочница» |
| `Session.dc.html` | C · Экран открытого сеанса |
| `Machines.dc.html` | Машины |
| `Network.dc.html` | Сеть |
| `Audit.dc.html` | Аудит |
| `Profile.dc.html` | Профиль агента |
| `Review.dc.html` | Проверка изменений профиля |
| `Settings.dc.html` | Настройки: политика по умолчанию |

Не выбраны, оставлены для сравнения: `Feed`, `Console` (D), `Board` (E), `Palette` (F), `Map` (G), `Wizard` (H).

На макетах есть функции, которых пока нет в коде: срок жизни песочницы и закрытие при простое, политика по умолчанию для новых песочниц, предупреждение о токенах в MCP-конфиге, подсветка подозрительных строк в diff, уровни риска.

## presentation/

Мини-презентация «smolvm-web: изоляция ИИ-агентов» для руководителя: `deck.json` (порядок слайдов) и `slides/*.html` (по слайду на файл, заметки докладчика — в `<aside>`).
