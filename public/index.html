Прокси

Для работы за корпоративным прокси без прямого доступа в интернет: образы, pip, npm, apt, git, curl внутри машин ходят через прокси.

Сертификаты

Корпоративные корневые сертификаты: TLS-инспекция на прокси, внутренние репозитории и сервисы.

Корпоративные репозитории

JFrog Artifactory, Nexus, Harbor: образы, pip, npm, apt, Go и GitHub releases из внутренних зеркал.

Логин к реестру образов передаётся smolvm на хосте (как docker login) и в машину не попадает. Адреса репозиториев автоматически разрешены фильтру «Сеть». Для https://-репозиториев машина получает сертификаты, которым доверяет этот компьютер (внутренний CA — тоже). smolvm serve, запущенный smolvm-web (--autostart), подхватывает логин сразу; если вы запускаете его сами, задайте ему DOCKER_CONFIG=<папка настроек smolvm-web>/docker.

Аудит и SIEM

Отправка журнала действий и сетевых событий в SIEM, оповещения о всплесках заблокированных соединений (попытки вывести данные). Сохраняются кнопками в карточках. Сам журнал — на странице «Аудит».

Секреты

Зашифрованное хранилище API-ключей и токенов. Сохраняются сразу, кнопкой «Сохранить секрет».
