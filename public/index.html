Ветка от

Copy-on-write клон работающей машины: память, процессы и диски продолжат работу с той же точки. Источник должен быть запущен с флагом branchable.

Подтверждение

Сеть, прокси и сертификаты

Для работы за корпоративным прокси без прямого доступа в интернет: образы, pip, npm, apk/apt, git, curl внутри машин будут ходить через прокси.

Новые настройки применяются к следующим запускам. Для уже запущенной машины нажмите «Применить прокси» в её карточке.
